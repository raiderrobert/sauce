# README opening

## Preferred — existing README

```markdown
Find out who owns what across your GitHub org.

Reconciles three ownership signals — CODEOWNERS, Backstage `catalog-info.yaml`, and GitHub team permissions — and tells you where they agree, disagree, or have gone stale.
```

## Counterexample — generated opening

```markdown
A command-line tool for three-way ownership reconciliation across GitHub CODEOWNERS, Backstage `catalog-info.yaml`, and GitHub Teams.

Audit an organization or a single repository to find conflicting ownership, missing metadata, and references to nonexistent teams.
```

## What differs

The preferred opening starts with what the reader wants to find out, then explains what the tool compares. It keeps the technical names without making the reader unpack “three-way ownership reconciliation” first.
