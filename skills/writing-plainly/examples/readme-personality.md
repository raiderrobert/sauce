Skills that make you feel like you're able to slow down and see all of the universe in all its expanse and the eternity past and future in a moment.

## Counterexample — generated opening

```markdown
Robert Roskam’s personal skills and prompts for research, code review, skill authoring, specification writing, and architecture visualization.
```

## What differs

The preferred version is longer and more dramatic. The user values its personality over a neutral inventory of capabilities. Preserve that intentional playfulness rather than editing it away in the name of plain language. This is not a template for making every introduction dramatic.
